## Data handling

The plugin sends data off-site in exactly two cases:

- **Expo** (`https://exp.host`) receives push tokens and message content, because that is how
  delivery works.
- **GitHub** (`https://api.github.com`) is contacted to check for plugin updates.

Form submissions and device records stay in your own database. Nothing is sent to MrDemonWolf, Inc.
